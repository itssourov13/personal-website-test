Part one covered the shipping-address field. The pattern repeats across
phone number inputs (wrong keyboard type on mobile), payment fields
(fighting password managers instead of working with them), and anything
with a country-specific format assumed to be American.

The fix is the same every time: watch a real session before touching the
visual design. The mechanical failure is almost always more interesting —
and more fixable — than the layout.
